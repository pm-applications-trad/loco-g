### 1.2 Market Opportunity

- **Party games** market oversaturated with single-mechanic apps — LocoGames combines multiple games in one
- **Drinking games** apps are mostly cheap clones — opportunity for premium, polished experience
- **Cross-promotion** between party/drinking/bundle is unique in this space — no competitor does a 3-app ecosystem
- **18+ premium branding** can command higher subscription prices — adult audience has disposable income
- **WebSocket multiplayer** is rare in party game apps — most use Bluetooth/local pass-and-play
- **AI-generated content** (categories, questions, challenges) is a major differentiator no competitor offers

## 3. Nano Banana Prompt Strategy

### 3.1 Overview

Nano Banana (AI content generation) will be used to generate dynamic, infinite content for multiple game types. This eliminates the need for static content packs and keeps games fresh.

### 3.2 Prompt Categories

#### 3.2.1 Never Have I Ever — Statement Generation

```
System: You are a party game content generator. Generate Never Have I Ever statements.

Parameters:
- Category: {mild|spicy|extreme|mixed}
- Count: {1–20}
- Language: {en|de|es|fr}
- Audience: Adult 18+ party game

Rules:
- Statements must be relatable, surprising, or funny
- Mix common experiences with rare ones
- Avoid offensive, racist, or discriminatory content
- Keep statements under 100 characters
- Format as JSON array of strings

Example output:
["Never have I ever lied about my age at a bar",
 "Never have I ever sent a text to the wrong person",
 "Never have I ever pretended to like a gift"]

Generate {count} "{category}" statements in {language}.
```

#### 3.2.2 Most Likely To — Scenario Generation

```
System: You are a party game content generator. Generate "Who is most likely to..." scenarios.

Parameters:
- Category: {funny|embarrassing|wild|mixed}
- Count: {1–20}
- Language: {en|de|es|fr}
- Audience: Adult 18+ party game

Rules:
- Scenarios should spark debate and laughter
- Avoid scenarios that could cause real conflict
- Vary difficulty and absurdity
- Keep under 120 characters
- Format as JSON array of strings

Example output:
["Who is most likely to become a millionaire?",
 "Who is most likely to survive a zombie apocalypse?",
 "Who is most likely to forget their own birthday?"]

Generate {count} "{category}" scenarios in {language}.
```

#### 3.2.3 Who Am I? — Category & Identity Generation

```
System: You are a party game content generator. Generate "Who Am I?" character identities.

Parameters:
- Category: {real_people|fictional_characters|objects|animals|custom}
- Count: {1–20}
- Difficulty: {easy|medium|hard}
- Language: {en|de|es|fr}
- Audience: Adult 18+ party game

Rules:
- Real people: globally known celebrities, historical figures, athletes
- Fictional: characters from movies, TV, books, games, mythology
- Objects: everyday items, famous objects, abstract concepts
- Animals: specific species, famous animals, mythical creatures
- Easy: instantly recognizable by 90%+ of people
- Medium: recognizable by 50%+
- Hard: recognizable by 20%+
- Provide identity + 3 hint keywords for each
- Format as JSON array of objects: [{"identity": "string", "hints": ["hint1","hint2","hint3"]}]

Example output:
[
  {"identity": "Albert Einstein", "hints": ["physics", "E=mc²", "wild hair"]},
  {"identity": "Toilet Paper", "hints": ["bathroom", "roll", "pandemic staple"]},
  {"identity": "Sherlock Holmes", "hints": ["detective", "221B", "pipe"]}
]

Generate {count} "{category}" identities at "{difficulty}" difficulty in {language}.
```

#### 3.2.4 Truth or Dare — Content Generation

```
System: You are a party game content generator for adults 18+. Generate Truth or Dare prompts.

Parameters:
- Type: {truth|dare|mixed}
- Dare Level: {mild|spicy|extreme}
- Count: {1–20}
- Language: {en|de|es|fr}
- Group Size: {groupSize}
- Audience: Adult 18+ party game

Rules:
- Truths: provocative but not traumatizing questions
- Dares — Mild: funny, slightly embarrassing (sing, dance, impersonate)
- Dares — Spicy: flirty, bold (compliment a stranger, reveal last text)
- Dares — Extreme: boundary-pushing (share a secret, do a dramatic reading)
- All dares must be safe and consensual
- Format as JSON array of strings

Generate {count} {type} prompts at "{dareLevel}" level for {groupSize} players in {language}.
```

#### 3.2.6 Guess Battle — Question Generation

```
System: You are a party game content generator. Generate Guess Battle questions with numerical answers.

Parameters:
- Category: {science|history|pop_culture|sports|nature|mixed}
- Count: 1–10
- Language: {en|de|es|fr}
- Audience: Adult 18+ party game

Rules:
- Questions must have a verifiable numerical answer
- Answers should NOT be common knowledge (aim for surprising)
- Provide exact answer + unit
- Include fun fact about the answer
- Format as JSON array of objects:
  [{"question": "string", "answer": number, "unit": "string", "fun_fact": "string"}]

Example output:
[
  {"question": "How many bones are in the adult human body?", "answer": 206, "unit": "bones", "fun_fact": "Babies are born with about 300 bones that fuse together as they grow."},
  {"question": "How many languages are spoken worldwide?", "answer": 7151, "unit": "languages", "fun_fact": "About 40% of languages are endangered."}
]

Generate {count} "{category}" questions in {language}.
```

### 3.4 Prompt Safety Filters

All generated content must pass safety validation:

| Filter | Rule |
|--------|------|
| Profanity | Block extreme profanity, allow mild |
| Hate Speech | Strict block on all forms |
| Violence | Block graphic violence descriptions |
| Personal Info | Block generation of real phone numbers, addresses |
| Underage | Block any content referencing minors |
| Self-harm | Strict block |
| GDPR | No personal data sent to LLM API |

## 6. Key Decisions

- **LLM Provider**: OpenAI GPT-4o via backend proxy (NOT direct from app — API key security)
- **Caching Strategy**: Hive local DB with TTL-based expiration (24h default)
- **Fallback**: All games work offline with bundled content; AI generation is enhancement, not requirement
- **Languages**: All prompts include language parameter; generate in all 4 supported languages
- **Cost Management**: Backend rate-limits per user (10 generations/day free, 50/day premium)
- **Content Review**: User-reported content flagged for manual review; generated content not moderated pre-delivery (speed over safety — user reports handle edge cases)

## 7. Risks & Mitigations

| Risk | Probability | Impact | Mitigation |
|------|------------|--------|------------|
| LLM API costs exceed budget | Medium | High | Aggressive caching, rate limiting, bundled content fallback |
| Generated content quality inconsistency | High | Medium | Prompt engineering iteration, user feedback loop, manual review sampling |
| Offensive AI-generated content | Low | High | Safety filter layer, content reporting, human-in-the-loop escalation |
| API latency degrades UX | Medium | Medium | Pre-fetch and cache during idle; show loading skeletons |
| Competitor copies AI generation feature | High | Low | First-mover advantage, prompt IP, brand stickiness from multi-game ecosystem |

## Appendix B: Localization Notes

All generated content localization follows this pipeline:

```
1. Generate in English (highest quality LLM output)
2. Cache English version
3. On user request: translate via same LLM to target language
4. Cache translated version
5. Serve from cache on subsequent requests
```

Translation quality will be monitored and tuned per language with native-speaker review sampling.
